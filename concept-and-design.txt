1日に1回LINEに通知してくれる。
その通知で、今日の気分と、今日の出来事を１つ教えてと聞いてくれてる
その回答をLINEで返すと、その返答を記録してくれる。
オプションとして、追加で定型の質問を何パターンか並べて、その回答も記録する。
定型質問の例：
1. 今日何を食べた？
2. 今日頑張ったことは？
3. 今日できなかったことは？
4. 明日やりたいことは？

１週間分をAIが整理してレポートにしてくれる。

複数ユーザでの使用を想定
最終的に商用化したい。

ユーザインターフェース：LINE(LINE Messaging APIで連携)
バックエンド：FASTAPI
データベース：Cloud SQL
ホスティング：Cloud Run
AI処理：Gemini API

日記の入力方法：
LINEのトークで変身された内容をそのまま記録する。AIで処理はしない。

オプション定型質問のトリガー: 
毎日の日記回答後、定型質問をリストし、回答したいものを選択させる

通知・レポート時間: 
個人設定を可能にする
